Usulan desain yang perlu kamu review

1. Navigasi bawah 4 menu + tombol +: Home · Transaksi · (+) · Stats · Lainnya. Tujuh menu terlalu sempit di bawah.
2. Transaction + History digabung jadi satu tab "Transaksi" dengan tombol Daftar / Kalender.
3. Pocket, Budget, Setting masuk ke "Lainnya". Budget tetap terlihat di Home.
4. Kartu saldo Home: kartu pertama total, geser untuk tiap pocket. Ikon 👁️ menyembunyikan angka.
5. Font ketiga: Kiro Crew memakai font Assistant (gratis, Google Fonts).
6. Tombol + di tengah bawah, mudah dijangkau jempol kiri dan kanan.
